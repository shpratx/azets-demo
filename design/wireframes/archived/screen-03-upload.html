Validation Rules
F1.1.4 Schema Validation F1.1.5 Error Reporting
✓ The following rules will be applied on upload
  • Account Code must be present and unique across all rows
  • Account Name must not be null or empty string
  • Account Type must be one of: Asset, Liability, Equity, Revenue, Expense
  • Parent Code, if provided, must reference an existing Account Code in the file
  • Currency, if provided, must be a valid ISO 4217 currency code (e.g. GBP, EUR, USD)
File will be parsed and validated. You'll see detailed results on the next screen.
📌 Upload Guidelines
Max file size 50 MB
Accepted formats CSV, XLSX, XML
Max rows 100,000 accounts
Encoding UTF-8 preferred
Date format YYYY-MM-DD or DD/MM/YYYY
Header row Required (row 1)
